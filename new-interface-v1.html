الفهرس

المخطط العام لتوزيع الكهرباء

سيتم إدراج المخطط العام التفاعلي ومسارات RMU → TR → FED → ATS → MDP → MP → PP في هذا القسم.

المحول رقم 1 — TR1

صفحة المحول والرسومات واللوحات التابعة له.

المحول رقم 2 — TR2

RMU1 → TR2 → FED2 → ATS4 → MDP2

المحول رقم 3 — TR3

RMU1 → TR3 → FED3 → ATS5 → MDP3

المحول رقم 4 — TR4

صفحة المحول الرابع واللوحات التابعة له. المولد رقم 3 خاص بالمحول 4.

المحول رقم 5 — TR5

صفحة المحول الخامس واللوحات التابعة له.

مولدات المستشفى

تسجيل جميع المولدات، مع الشرح التفصيلي للمولدات 1 و2 و3 حسب البيانات المعتمدة.

المولدان 1 و2 مرتبطان بمنظومة المحولين 2 و3. المولد 3 خاص بالمحول 4.
