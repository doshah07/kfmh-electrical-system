# KFMH Electrical Distribution Management System

نظام داخلي ثنائي اللغة لتوثيق وإدارة توزيع الكهرباء في المستشفى العسكري.

## الفرع الجاري تطويره

`rebuild-v2`

تم إنشاء هذا الفرع لإعادة بناء الموقع بشكل منظم دون التأثير على ملفات الفرع الرئيسي القديم حتى اكتمال المراجعة.

## الهيكل المعتمد

`RMU → TR → FED → ATS → MDP → MP → PP`

المسارات التي لا تحتوي FED أو ATS تظهر وفق الواقع الفعلي، مثل مسار MDP1.

## الصفحات والوظائف المنفذة

- الصفحة الرئيسية ولوحة مؤشرات.
- صفحات مستقلة للمحولات TR1 إلى TR5.
- صفحات MDP1 إلى MDP5.
- صفحات جميع لوحات MP الموجودة ضمن البيانات الحالية.
- صفحات لوحات PP وروابط مستقلة لكل لوحة.
- البحث بالرمز والاسم والموقع والسعة ومسار المصدر.
- المخطط العام.
- قسم مولدات المستشفى.
- قسم البطاريات وأنظمة UPS.
- مركز الطباعة.
- فهرس سريع يبدأ بـ MDP1 إلى MDP5 ثم روابط MP التابعة.
- رمز QR ورابط مستقل في صفحات TR وMDP وMP وPP.
- واجهة عربية وإنجليزية متجاوبة مع الجوال.
- منع فهرسة النسخة التجريبية بمحركات البحث.

## نظام الطباعة

الطباعة مقتصرة على العناصر المعتمدة:

- صفحة المحول.
- صفحة Main Panel (MP).
- صفحة Power Panel (PP).
- الملصقات.
- المخطط العام.

ملصق PP الداخلي يستخدم الحقول الثلاثة فقط:

- `TAG No.`
- `SOURCE`
- `LOCATION`

## حالة البيانات

- MDP1 وMDP2 وMDP3 مبنية على البيانات المؤكدة المتاحة.
- MDP4 وMDP5 تحتويان الهيكل وعدد مخارج MP فقط، وتظهر التفاصيل غير المستلمة على أنها **قيد التوثيق**.
- بيانات المولدات والبطاريات وUPS لم تُخترع؛ تظهر كأقسام بانتظار البيانات المعتمدة.
- المواقع غير المستلمة تظهر بوضوح على أنها **قيد التحديث**.

## التشغيل المحلي

شغّل خادم ملفات ثابت داخل مجلد المشروع:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## النشر

لا يتم دمج `rebuild-v2` في `main` أو نشره كنسخة إنتاجية قبل المراجعة والاعتماد.
